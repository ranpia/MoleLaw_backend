# 임베딩 모델 선정

2026-10-19, 네 모델·세 청크·원본/정제 질문 평가를 바탕으로 **검색 품질 기준 모델을 KURE-v1, 1024차원, 300자 청크·중복 64자**로 선정한다. Qdrant 코사인 검색을 사용하고 조문 순위는 자식 청크 점수의 최댓값으로 계산한다. 애플리케이션의 모델 설정·전체 법령 색인을 전환한 상태를 뜻하지 않는다.

## 선정 근거

미리 정한 선택 기준은 **정제 질문의 개발용 Recall@5**다. 검증용 최고 점수에 맞춰 선택 기준을 바꾸지 않는다. 아래는 각 후보 구성의 정제 질문 결과다.

| 구성 | 개발용 Recall@5 | 검증용 Recall@5 | 검증용 전체 MRR |
| --- | ---: | ---: | ---: |
| **KURE-v1 300자** | **75.17%** | 80.52% | 0.7346 |
| BGE-M3 500자 | 72.67% | 80.48% | 0.7949 |
| Qwen3-0.6B 300자 | 72.67% | 80.02% | 0.7597 |
| EmbeddingGemma 500자 | 72.00% | 80.81% | 0.8136 |
| Qwen3-0.6B 500자 | 67.67% | **82.17%** | 0.7872 |

법령 검색에서는 답변에 필요한 근거를 누락하지 않는 것을 우선한다. KURE 300자는 이 기준의 개발용 회수율이 가장 높다. Qwen3 500자의 검증용 회수율이나 Gemma 500자의 첫 정답 순위는 더 높지만, 그 결과를 보고 선택 기준을 바꾸지 않는다. 이 결정은 이번 작은 탐색 평가에 대한 기준선 선정이며 일반적인 모델 우열의 증명은 아니다.

## 고정할 조건

- 모델: `nlpai-lab/KURE-v1`, revision `8b418a58414668e75532ed045c22d9ca018ae2b2`
- 벡터: 1024차원, CLS 풀링·L2 정규화, 코사인 유사도, 차원 축소 없음
- 문서 입력: `{title}\n{text}`
- 검색 질문 입력: `{text}`. 모델 전용 접두사는 없으며 정제된 질문을 이 자리에 넣는다.
- 청킹: 최대 300자, 중복 64자, 조문 단위 보존. 토큰 기준이 아니다.
- 검색: Qdrant에서 `unit_id`별 최대 자식 청크 점수로 조문 순위 계산. 이번 상위 5개 지표는 서로 다른 조문 기준이다.

KURE-v1은 BGE-M3 기반 한국어 추가 학습 모델이며 공식 모델 카드는 MIT 라이선스를 명시한다. [공식 모델](https://huggingface.co/nlpai-lab/KURE-v1)을 참고한다. 같은 차원의 BGE-M3·Qwen3 벡터와 혼합하지 않는다.

## 적용 범위와 남은 구현

이 선택은 **질문 정제를 사용하는 검색 방식**에 대한 것이다. 원본 질문만 쓰는 조건의 개발용 Recall@5 최고 구성은 Qwen3 500자(66.17%)였으므로, 정제를 제거해도 KURE가 최선이라고 해석하지 않는다.

정제 실험은 어시스턴트가 작성해 고정한 110개 질문으로 수행했다. 실제 서비스 LLM의 정제 품질·지연시간·비용과 생성 답변 정확도는 검증하지 않았다. 서비스에서는 동일한 의미 보존 원칙의 질문 정제와 모델 입력 계약을 구현해야 한다.

300자 코퍼스는 8,497개 청크로 500자의 6,634개보다 약 28% 많다. 저장·색인 부담을 감수하는 선택이다. 검색 청크 크기를 답변 문맥 길이로 제한하지 말고, 검색된 조문 ID로 원문과 필요한 주변 근거를 구성하는 방식은 서비스 적용 시 별도로 구현한다. 현재 평가가 자동 문맥 확장이나 완성된 서비스 RAG를 검증한 것은 아니다.

실험 CPU 런타임과 배포 서버 성능은 구분한다. 이번 선정은 운영 지연시간·동시 처리량을 보장하지 않으며, 기존 실험 컬렉션과 다른 모델 결과는 비교·회귀 검증용으로 보존한다.
