# 임베딩 모델 선정

## 2026-10-20 이후 평가 지표 우선순위

사용자 요구에 따라 **Hit@5와 Complete@5를 공동 우선 지표**로 사용한다. Hit@5는 상위 5개에서 필요한 정답 조문을 하나 이상 찾은 질문의 비율, Complete@5는 필요한 정답 조문을 전부 찾은 질문의 비율이다. Recall·MRR·nDCG·지연은 보조 지표로 유지한다. 두 우선 지표가 상충하면 임의 가중치로 단일 우승을 만들지 않고 나누어 보고한다.

이번 법률 쟁점 변환의 500자는 Hit@5 20/36(55.56%)로 700자와 같고 Complete@5 4/36(11.11%)로 700자의 3/36(8.33%)보다 높아 후속 비교의 유력 후보다. 한 문항 차이의 작은 튜닝 표본이며 운영 확정은 아니다. 예전 모델 비교의 사전 개발용 Recall@5 선정 기준과 원자료는 당시 기록으로 보존한다. 이번 우선순위 변경을 과거 실험의 사전 기준이었던 것처럼 표시하지 않는다.

2026-10-20 후속 판단: 독립 질문 검증의 정제 Recall@5 16.44%, Complete@5 8.33%로 서비스 적용 확정은 보류한다. 아래 선정은 기존 비교의 기준 모델 선택 기록으로 유지한다. [독립 결과와 고정 정답 한계](../reports/independent-validation-v1/kure-v1/interpretation.md)를 함께 참고한다.

2026-10-19, 네 모델·세 청크·원본/정제 질문 평가를 바탕으로 **검색 품질 기준 모델을 KURE-v1, 1024차원, 300자 청크·중복 64자**로 선정한다. Qdrant 코사인 검색을 사용하고 조문 순위는 자식 청크 점수의 최댓값으로 계산한다. 애플리케이션의 모델 설정·전체 법령 색인을 전환한 상태를 뜻하지 않는다.

## 선정 근거

미리 정한 선택 기준은 **정제 질문의 개발용 Recall@5**다. 검증용 최고 점수에 맞춰 선택 기준을 바꾸지 않는다. 아래는 각 후보 구성의 정제 질문 결과다.

| 구성 | 개발용 Recall@5 | 검증용 Recall@5 | 검증용 전체 MRR |
| --- | ---: | ---: | ---: |
| **KURE-v1 300자** | **75.17%** | 80.52% | 0.7346 |
| BGE-M3 500자 | 72.67% | 80.48% | 0.7949 |
| Qwen3-0.6B 300자 | 72.67% | 80.02% | 0.7597 |
| EmbeddingGemma 500자 | 72.00% | 80.81% | 0.8136 |
| Qwen3-0.6B 500자 | 67.67% | **82.17%** | 0.7872 |

법령 검색에서는 답변에 필요한 근거를 누락하지 않는 것을 우선한다. KURE 300자는 이 기준의 개발용 회수율이 가장 높다. Qwen3 500자의 검증용 회수율이나 Gemma 500자의 첫 정답 순위는 더 높지만, 그 결과를 보고 선택 기준을 바꾸지 않는다. 이 결정은 이번 작은 탐색 평가에 대한 기준선 선정이며 일반적인 모델 우열의 증명은 아니다.

## 고정할 조건

- 모델: `nlpai-lab/KURE-v1`, revision `8b418a58414668e75532ed045c22d9ca018ae2b2`
- 벡터: 1024차원, CLS 풀링·L2 정규화, 코사인 유사도, 차원 축소 없음
- 문서 입력: `{title}\n{text}`
- 검색 질문 입력: `{text}`. 모델 전용 접두사는 없으며 정제된 질문을 이 자리에 넣는다.
- 청킹: 최대 300자, 중복 64자, 조문 단위 보존. 토큰 기준이 아니다.
- 검색: Qdrant에서 `unit_id`별 최대 자식 청크 점수로 조문 순위 계산. 이번 상위 5개 지표는 서로 다른 조문 기준이다.

KURE-v1은 BGE-M3 기반 한국어 추가 학습 모델이며 공식 모델 카드는 MIT 라이선스를 명시한다. [공식 모델](https://huggingface.co/nlpai-lab/KURE-v1)을 참고한다. 같은 차원의 BGE-M3·Qwen3 벡터와 혼합하지 않는다.

## 적용 범위와 남은 구현

이 선택은 **질문 정제를 사용하는 검색 방식**에 대한 것이다. 원본 질문만 쓰는 조건의 개발용 Recall@5 최고 구성은 Qwen3 500자(66.17%)였으므로, 정제를 제거해도 KURE가 최선이라고 해석하지 않는다.

정제 실험은 어시스턴트가 작성해 고정한 110개 질문으로 수행했다. 실제 서비스 LLM의 정제 품질·지연시간·비용과 생성 답변 정확도는 검증하지 않았다. 서비스에서는 동일한 의미 보존 원칙의 질문 정제와 모델 입력 계약을 구현해야 한다.

300자 코퍼스는 8,497개 청크로 500자의 6,634개보다 약 28% 많다. 저장·색인 부담을 감수하는 선택이다. 검색 청크 크기를 답변 문맥 길이로 제한하지 말고, 검색된 조문 ID로 원문과 필요한 주변 근거를 구성하는 방식은 서비스 적용 시 별도로 구현한다. 현재 평가가 자동 문맥 확장이나 완성된 서비스 RAG를 검증한 것은 아니다.

실험 CPU 런타임과 배포 서버 성능은 구분한다. 이번 선정은 운영 지연시간·동시 처리량을 보장하지 않으며, 기존 실험 컬렉션과 다른 모델 결과는 비교·회귀 검증용으로 보존한다.

근거: [전체 지표](../reports/chunk-experiments/comparison.md), [정렬된 요약](../reports/chunk-experiments/overview.md), [KURE 결과](../reports/kure-v1/README.md).

## 선정 후 확대 검증

[확대 검증](../reports/final-validation-v1/kure-v1/README.md)을 완료했으며 사전 고정한 검색 기준 네 가지를 모두 통과해 선정을 유지한다. 주 법령 30개·질문 270개, 10,999개 청크에서 모델·청크·수용 기준값을 고정했다. 신규 양성 120개의 정제 Recall@5는 99.17%, Complete@5는 98.33%, MRR@10은 0.9472이며 기존 검증용 정제 Recall@5는 80.52%를 유지했다.

신규 질문은 원문을 보며 작성한 표적 평가이므로 일반 사용자 질문의 성능으로 확대 해석하지 않는다. 신규 음성 40개 중 11개(27.5%)가 고정 유사도 기준값을 통과했다. 이는 LLM의 근거 충분성 판단이나 생성 답변 오류를 측정한 수치가 아니다. 실제 질문 정제·근거 충분성 판단·누락 법령 수집 후 재검색은 후속 개발·평가 범위이며 서비스 준비 상태는 `serviceReady=false`로 유지한다. 개발 계획은 dev 브랜치의 `docs/plans/adaptive-law-retrieval.md`에서 관리한다.

## 임계값 사후 조정 (2026-10-20)

사용자 요청으로 저장된 독립 질문 점수의 임계값을 탐색했다. 이 자료는 앞으로 임계값 튜닝용으로 취급하며, 여기서 고른 값의 독립 검증 자료로 재사용하지 않는다. 기존 고정 입력·검색 결과·기준값 기록은 유지했고 서비스에는 적용하지 않았다. 정제 기준값 약 0.586에서 코퍼스 내 16/36개·그 외 13/64개가 수용되며, 약 0.535에서는 각각 26/36개·43/64개로 함께 증가한다. 임계값만으로 검색 순위나 원래 Recall@5는 개선되지 않는다. [그래프·후보·전체 수치](../reports/threshold-sweep-v1/README.md)를 참고한다.

## 법률 쟁점 중심 단일 질의 변환 비교 (2026-10-20)

원본만 읽은 작성 역할과 독립 의미 검수를 거친 새 변환 100개를 평가했다. 코퍼스 내 36문항에서 Recall@5는 원본 14.12%·기존 정제 16.44%·법률 쟁점 변환 28.70%, MRR@10은 각각 0.1755·0.1463·0.3540이다. 새 변환은 정답을 하나 이상 찾은 질문을 11개에서 18개로 늘렸으나 전부 찾은 질문은 3개로 그대로다. 추가 자료 필요 질문의 점수 수용도 3/44에서 11/44로 증가해 근거 충분성 판단과 분리한다. 전략의 효과를 보는 탐색 비교이며 서비스 적용 확정이나 sparse 대체 검증은 아니다. [그래프·결과·한계](../reports/legal-query-transform-v1/kure-v1/interpretation.md)를 참고한다.

## Recall@50 후보 회수 확인 (2026-10-20)

모델 추론 없이 기존 질문 벡터로 상위 50개 조문을 조회했다. 법률 쟁점 변환 Recall@50은 300자 55.42%·500자 56.57%·700자 57.27%다. 500·700자의 Hit@50은 30/36, Complete@50은 11/36으로 재정렬만으로 복구 가능한 후보의 한계를 보여준다. Hit@5·Complete@5를 우선 지표로 유지하며 기존 상위 5개 품질은 이번 조회로 바뀌지 않는다. [원자료·해석](../reports/recall50-v1/kure-v1/README.md)를 참고한다.
