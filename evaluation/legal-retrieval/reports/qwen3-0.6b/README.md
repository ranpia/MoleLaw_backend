# Qwen3-Embedding-0.6B 결과 안내

공식 체크포인트 `97b0c614be4d77ee51c0cef4e5f07c00f9eb65b3`, 1024차원, CPU float32로 평가한다. 한국어 전용 파인튜닝 모델이 아닌 다국어 모델이다. [실행 조건과 질문 지시문](../../../../docker/qwen3/README.md)을 참고한다.

최신 완료 조건과 수치는 [그래프·정렬된 요약](../chunk-experiments/overview.md), [원본·정제 전체 지표](../chunk-experiments/comparison.md), [CSV](../chunk-experiments/comparison.csv)를 기준으로 확인한다. 실행 중인 청크는 확정 비교에 포함하지 않는다.

원본 질문 결과는 이 폴더의 `char<크기>-overlap64-article-v1/`에, 정제 질문 결과는 `reports/query-rewrite-v1/` 아래에 저장한다. 300·500자는 각각 `char300/qwen3-0.6b/`·`char500/qwen3-0.6b/`, 700자는 호환성을 위해 `qwen3-0.6b/` 경로를 사용한다. 해당 평가가 완료된 뒤 결과 파일을 공개한다.

문서 벡터와 질문·정답·검색 결과는 Qdrant에 보존한다. 모든 모델에 같은 원본 질문·정제본 110개와 같은 정답·분할을 적용한다. 정제본은 새로 생성하지 않는다. 각 구성의 개발용 양성 30개와 검증용 양성 70개를 따로 집계하며, 음성 질문은 분할별 5개다.

## 청크별 원본·정제 비교

300·500·700자에서 원본·정제 질문 평가와 Qdrant 적재·검증을 모두 완료했다. 아래 MRR은 정제 질문의 검증용 전체 순위 값이다.

| 문자 | 개발용 Recall@5 원본 → 정제 | 검증용 Recall@5 원본 → 정제 | 검증용 정제 MRR |
| ---: | ---: | ---: | ---: |
| 300 | 62.67% → 72.67% | 74.90% → 80.02% | 0.7597 |
| 500 | 66.17% → 67.67% | 78.40% → 82.17% | 0.7872 |
| 700 | 62.83% → 67.67% | 77.69% → 80.79% | 0.7771 |

개발용 Recall@5 기준으로 Qwen3의 우선 후보는 300자(72.67%)다. 검증용 Recall@5와 MRR은 500자가 더 높았다. 검증용 최고값을 보고 개발용 선택 기준을 바꾸지 않는다.

전체 순위 MRR은 기존 전수 순위 평가값을 보존해 집계하며, Qdrant 상위 10개로 계산한 MRR@10과 다르다. 유사도는 정답 확률이 아니다. [평가지표 설명](../similarity-and-metrics.md)을 참고한다.
