# BGE-M3 법령 검색 평가

2026-10-16 300 / 500 / 700문자 평가 완료. 기본 출력 1,024차원, 중복 64문자, source unit 5,486개, 동일 질문 110개다. CPU 6 threads / batch 16 조건에서 순차 실행했으며 기존 정상 벡터 캐시를 재사용했다.

| 최대 문자 | Development Recall@5 | Development MRR | Development Recall@10 |
| ---: | ---: | ---: | ---: |
| 300 | 57.39% | 0.5196 | 70.83% |
| 500 | 64.06% | 0.5928 | 76.67% |
| 700 | 65.72% | 0.5909 | 73.33% |

미리 정한 1차 지표 Recall@5에서는 700문자가 가장 높다. 다만 500문자와 차이는 1.67%p이며, 개발 질문 양성은 30개이고 MRR·Recall@10은 500문자가 높다. 따라서 BGE 내 700문자를 우선 후보, 500문자를 보조 후보로 남기며 확정적인 우열이나 최종 서비스 모델 선정을 주장하지 않는다. 한국어 추가 학습 후보까지 평가 범위를 확장할 계획이다.

각 청크 폴더의 summary.json·summary.csv·queries.csv·top10.csv에 전체 결과를 보존했다. [공통 비교표](../comparison.md)와 [CSV](../comparison.csv)는 원문·질문·정답·분할 identity 및 보고서 완료 여부를 검사한 결과만 포함한다. 500문자 보고서는 기존 원본을 보존하고 identity를 입력 해시 대조 후 계산했다.

음성은 분할별 5개뿐이며 생성 답변의 안전성 평가는 아니다. 캐시 재사용량이 다르므로 실행별 색인 시간을 모델 자체의 처리 속도로 비교하지 않는다. Qdrant ANN 또는 서비스 RAG는 실행하지 않았다.
