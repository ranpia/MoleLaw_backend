# BGE-M3 법령 검색 평가

## 300·500·700문자 정제 질문 비교

같은 정제 질문과 기존 문서 벡터로 평가했다. 모델·청크·질문 정제의 전체 지표와 Qdrant 결과는 [통합 비교](../chunk-experiments/comparison.md)를 참고한다.

| 문자 | 개발용 Recall@5 원본 → 정제 | 검증용 Recall@5 원본 → 정제 | 검증용 정제 MRR |
| ---: | ---: | ---: | ---: |
| 300 | 57.39% → 71.00% | 72.79% → 80.83% | 0.7577 |
| 500 | 64.06% → 72.67% | 75.40% → 80.48% | 0.7949 |
| 700 | 65.72% → 70.17% | 73.62% → 80.95% | 0.8036 |

정제 입력에서는 개발용 Recall@5가 500문자에서 가장 높다. 원본 입력의 우선 후보인 700문자와 달라졌으므로 청크와 입력 방식을 함께 비교해야 한다. 검증용 결과만 보고 반복 선택하지 않는다.

2026-10-16 300 / 500 / 700문자 평가 완료. 기본 출력 1,024차원, 중복 64문자, source unit 5,486개, 동일 질문 110개다. CPU 6 threads / batch 16 조건에서 순차 실행했으며 기존 정상 벡터 캐시를 재사용했다.

| 최대 문자 | Recall@5 | Recall@10 | MRR | Hit@5 | Complete@5 | Precision@5 | nDCG@5 | nDCG@10 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 300 | 57.39% | 70.83% | 0.5196 | 70% | 43.33% | 18.67% | 0.4725 | 0.5238 |
| 500 | 64.06% | 76.67% | 0.5928 | 76.67% | 50% | 20% | 0.5377 | 0.5863 |
| 700 | 65.72% | 73.33% | 0.5909 | 80% | 50% | 21.33% | 0.5469 | 0.5791 |

미리 정한 1차 지표 Recall@5에서는 700문자가 가장 높다. 다만 500문자와 차이는 1.67%p이며, 개발 질문 양성은 30개이고 MRR·Recall@10은 500문자가 높다. 따라서 BGE 내 700문자를 우선 후보, 500문자를 보조 후보로 남기며 확정적인 우열이나 최종 서비스 모델 선정을 주장하지 않는다. 한국어 추가 학습 모델 KURE-v1도 같은 세 청크 조건의 평가를 완료했다.

각 청크 폴더의 summary.json·summary.csv·queries.csv·top10.csv에 전체 결과를 보존했다. [공통 비교표](../comparison.md)와 [CSV](../comparison.csv)는 원문·질문·정답·분할 identity 및 보고서 완료 여부를 검사한 결과만 포함한다. 500문자 보고서는 기존 원본을 보존하고 identity를 입력 해시 대조 후 계산했다.

음성은 분할별 5개뿐이며 생성 답변의 안전성 평가는 아니다. 캐시 재사용량이 다르므로 실행별 색인 시간을 모델 자체의 처리 속도로 비교하지 않는다. 이 초기 원본 보고서는 로컬 전수 평가 기록이다. 후속 Qdrant 전수·근사 평가는 통합 비교에 반영했으며, 서비스 RAG의 답변 생성은 평가하지 않았다.

표의 값은 개발용 양성 30개 기준이다. Recall은 필요한 근거 중 찾은 비율, Hit는 하나 이상 찾은 질문의 비율, Complete는 전부 찾은 질문의 비율이다. Precision은 가져온 5개 중 정답 비율이며 MRR은 첫 정답의 위치, nDCG는 여러 정답의 배치를 본다. 모두 높을수록 좋지만 정답 확률은 아니다. [숫자 예시와 쉬운 설명](../similarity-and-metrics.md), [모델·분할별 통합 비교](../comparison.md)를 함께 참고한다.
