# 독립 질문 검증 결과 해석

2026-10-20 완료. 질문 작성·정답 확인·별도 검수를 분리한 100문항을 고정하고 원본·정제 200회 검색했다. KURE revision·1024차원·300자·중복 64자·기존 10,999개 문서 벡터·유사도 기준값을 유지했다. 결과를 보고 정답이나 질문을 수정하지 않았다.

## 코퍼스 내 36문항의 결과

| 지표 | 원본 질문 | 정제 질문 |
| --- | ---: | ---: |
| Recall@5 | 14.12% | 16.44% |
| Recall@10 | 21.53% | 23.84% |
| Hit@5: 정답을 하나 이상 찾은 질문 | 25.00% (9/36) | 30.56% (11/36) |
| Complete@5: 정답을 모두 찾은 질문 | 8.33% (3/36) | 8.33% (3/36) |
| MRR@10 | 0.1755 | 0.1463 |

정제로 Recall@5는 약 2.31%p 증가했지만 첫 정답 순위 지표 MRR@10은 낮아졌다. 정제가 모든 지표를 개선하지 않았고, 필요한 근거를 모두 찾은 문항 수도 늘지 않았다. 고정 정답 기준으로 현재 검색 구성이 일상적인 새 질문에 충분하다는 증거는 확보하지 못했다.

이전 확대 검증의 신규 정제 Recall@5 99.17%와 이번 16.44%는 질문 작성 방식·난이도·정답 개수·법령 분포가 다른 평가다. 같은 문항에서 모델 성능이 하락한 수치가 아니다. 앞선 질문은 공식 원문을 보며 작성했고 이번 질문은 원문과 정답을 보지 않은 역할이 작성했다. 앞선 높은 점수만으로 서비스 검색 성능을 확정할 수 없다. 이번에는 KURE만 평가했으므로 다른 모델이 더 좋다고 결론 내리지 않는다.

## 검색 성능과 자료 범위의 구분

100개 중 현재 자료로 핵심 법적 근거를 확보할 수 있다고 분류한 문항은 36개다. 추가 법령·규칙·판례 등 자료가 필요한 44개는 위 검색 정답 지표에서 제외했다. 해외 관할·개인 사건 조회 15개, 명시적으로 핵심 사실이 부족한 5개도 별도 집계했다. 이 분포는 의도적으로 만든 작은 질문셋의 분포이며 실제 사용자 질문의 처리 가능 비율이 아니다.

| 분류 | 문항 | 원본 점수 기준값 통과 | 정제 점수 기준값 통과 |
| --- | ---: | ---: | ---: |
| 추가 자료 필요 | 44 | 4/44 (9.09%) | 3/44 (6.82%) |
| 지원 범위 밖 | 15 | 3/15 (20.00%) | 2/15 (13.33%) |
| 핵심 사실 부족 | 5 | 1/5 (20.00%) | 3/5 (60.00%) |

이는 유사도 점수의 수용 여부이며 LLM이 범위를 판단한 결과가 아니다. 낮은 통과율은 범위 판정이 잘 됐다는 증거가 아니다. 코퍼스 내 질문도 원본 7/36, 정제 10/36만 같은 기준값을 통과했다. 현재 임계값을 서비스의 답변 가능/불가 판정으로 바로 사용하지 않는다. 사실 부족 5문항의 비율도 표본이 작아 일반화하지 않는다.

## 고정 정답의 한계와 실패 예시

정답 목록은 최소 충분 근거를 목표로 별도 검수했지만 사람 법률전문가가 검증한 완전한 정답 집합은 아니다. 정답 외 관련 조문이 검색되는 사례도 있다. 예를 들어 `ind-001` 보증금 미반환 질문의 정제 검색 1위는 주택임대차보호법 제3조의2(보증금의 회수), 유사도 0.6571이다. 고정 정답은 제3조의3·제4조·민법 제536조여서 Recall은 0으로 집계된다. 따라서 Recall 0을 검색된 모든 근거가 무관하다는 뜻으로 해석하지 않는다.

반면 `ind-011` 수습 최저임금 질문은 정제 검색 1·2위에 시행령 제3조와 법 제5조가 검색됐지만 상위 5개에서 단순노무직종 고시까지 모두 찾지는 못했다. 이처럼 하나의 관련 조문 검색과 질문에 필요한 근거 전체 확보를 나누어 봐야 한다. 문항별 점수·조문·정답 여부는 [상위 10개 결과](top10.csv)에 보존했다.

고정 정답은 이번 결과에 맞춰 바꾸지 않는다. 검색 후보를 섞어 별도 전문가가 대체 정답을 검토하는 작업이 필요하면 새 버전으로 수행하고 이번 점수는 원래 조건의 결과로 보존한다.

## 결정과 검증 상태

KURE는 기존 비교에서 선택한 검색 기준 모델로 보존한다. 서비스 적용을 확정할 근거는 부족하며 `serviceReady=false`를 유지한다. 현재 질문셋에서 다른 모델의 비교 성능, 실제 LLM의 의미 보존 정제·근거 충분성 판단, 누락 자료 수집 후 재검색, 답변 인용의 충실성은 검증하지 않았다.

입력·검토 파일 해시, 결과 200행·순위 2,000행, 양성 72회(36문항×2방식)의 지표 재계산, Qdrant 질문 아카이브 200포인트를 확인했다. KURE 컨테이너는 종료됐고 기존 문서 컬렉션과 실험 DB는 보존했다. 별도 에이전트는 정제 질문 3개에서 캐시와 Qdrant 질문 벡터, 전수 검색 상위 10개와 보관 결과를 대조했다. 직접 계산한 최대 자식 코사인 점수와 Qdrant 점수의 최대 차이는 약 3.16e-8로 표본 실행 경로는 일치했다. 전체 200개의 실행 경로를 같은 방식으로 검증한 것은 아니다. [표본 검토 근거](execution-check.json)를 보존한다.

## 임계값 사후 조정 (2026-10-20)

사용자 요청으로 저장된 독립 질문 점수의 임계값을 탐색했다. 이 자료는 앞으로 임계값 튜닝용으로 취급하며, 여기서 고른 값의 독립 검증 자료로 재사용하지 않는다. 기존 고정 입력·검색 결과·기준값 기록은 유지했고 서비스에는 적용하지 않았다. 정제 기준값 약 0.586에서 코퍼스 내 16/36개·그 외 13/64개가 수용되며, 약 0.535에서는 각각 26/36개·43/64개로 함께 증가한다. 임계값만으로 검색 순위나 원래 Recall@5는 개선되지 않는다.
