# 임베딩 실험 최종 정리

2026-10-20 문서 정리. 모델 비교와 확대 검증은 2026-10-19 완료했다.

검색 기준 모델은 **KURE-v1, 1024차원, 최대 300자·중복 64자, 질문 정제 사용**으로 확정한다. Qdrant 코사인 검색에서 조문별 자식 청크의 최대 점수로 순위를 매긴다. 서비스 모델 전환이나 답변 생성 검증이 완료된 상태는 아니다.

## 모델 비교와 선정

EmbeddingGemma·BGE-M3·KURE-v1·Qwen3-Embedding-0.6B 각각 300·500·700자의 12개 구성을 평가했다. 같은 주 법령 20개와 보충 자료, 원문 5,486개 단위, 질문 110개의 원본·정제본을 사용했다. 사전에 정한 정제 질문 개발용 Recall@5가 가장 높은 KURE 300자를 선택했다.

| 선정 구성의 지표 | 개발용 | 기존 검증용 |
| --- | ---: | ---: |
| 정제 Recall@5 | 75.17% | 80.52% |
| 정제 전체 순위 MRR | 0.7064 | 0.7346 |

Qwen3 500자의 검증용 정제 Recall@5는 82.17%였지만, 검증 결과를 보고 선정 기준을 바꾸지 않았다. 모든 지표에서 KURE가 최고라는 의미는 아니다. [모델·청크 그래프](chunk-experiments/overview.md), [전체 비교](chunk-experiments/comparison.md), [선정 조건과 revision](../review/model-selection.md)을 참고한다.

## 선정 조건을 고정한 확대 검증

주 법령 30개·원문 6,527개 단위·10,999개 청크로 확대했다. 기존 110문항에 신규 양성 120문항과 음성 40문항을 추가해 총 270문항, 원본·정제 540개 실행 결과를 남겼다. 기존 개발용으로 정한 유사도 기준값도 재조정하지 않았다.

| 평가 범위·질문 | Recall@5 | Complete@5 | MRR@10 | 음성 오수용률 |
| --- | ---: | ---: | ---: | ---: |
| 기존 검증용·원본 | 71.71% | 57.14% | 0.6532 | 40.00% (2/5) |
| 기존 검증용·정제 | 80.52% | 65.71% | 0.7306 | 40.00% (2/5) |
| 신규 검증용·원본 | 96.25% | 95.83% | 0.8784 | 27.50% (11/40) |
| 신규 검증용·정제 | 99.17% | 98.33% | 0.9472 | 27.50% (11/40) |

사전 기준인 신규 정제 Recall@5 ≥ 75%, Complete@5 ≥ 60%, 기존 검증용 정제 Recall@5 ≥ 75.52%, 신규 정제 회수율이 원본 이상이라는 네 조건을 모두 통과해 선정을 유지한다.

Recall@5는 필요한 정답 조문 중 상위 5개에서 찾은 비율의 질문별 평균이고, Complete@5는 필요한 조문을 모두 찾은 질문 비율이다. MRR@10은 첫 정답이 앞에 나올수록 높으며 10위 밖은 0점이다. 위 모델 비교의 전체 순위 MRR과 직접 비교하지 않는다. 음성 오수용률은 답변 근거가 없는 질문의 최고 유사도가 기준값을 통과한 비율이며 실제 생성 답변의 오답률은 아니다.

신규 질문은 공식 원문과 정답을 보며 어시스턴트가 작성했다. 단일 근거 100개·다중 근거 20개로 구성했고, 실제 사용자 질문이나 독립 블라인드 평가가 아니다. 신규 점수가 기존보다 높은 것을 모델 개선이나 전체 법령의 99% 검색 성능으로 해석하지 않는다. 실제 서비스 LLM이 질문을 정제한 실험도 아니다.

## 보존 상태와 후속 범위

실험 자료는 Qdrant에 보존하고 Git에는 고정 입력·설정·결과를 남겼다. 모델 서버는 실행 후 중지했다. DB 삭제·모델 변경·전체 재평가는 수행하지 않는다. 보존 결정 당시 Qdrant는 약 996MB, C드라이브 여유는 약 74GB였으며 확대 검증 후 용량을 다시 측정한 수치는 아니다. [컬렉션 안내](qdrant-lab/README.md)를 참고한다.

서비스 준비 상태는 `serviceReady=false`다. 실제 LLM의 의미 보존 정제, 근거 충분성 판단, 필요 법령 수집·벡터화 후 재검색, 인용 충실성·답변 품질·배포 성능을 다음 단계에서 검증한다. 이 개발 계획은 dev 브랜치의 `docs/plans/adaptive-law-retrieval.md`에서 관리한다. 이번 실험 브랜치는 검색 모델 선정과 검증 기록을 보존한다.
