# 법률 쟁점 중심 단일 질의 변환 비교 v1

2026-10-20 준비. 사용자 질문을 LLM이 법률 쟁점·핵심 용어 중심의 단일 dense 검색 질의로 변환하는 방식을 비교한다. 기존 의미 보존 정제는 주로 문장을 다듬는 방식이었다. 이번에는 원래 상황에서 드러나는 일반 법률 개념을 보강한다. 질문당 질의 1개·벡터 1개이며 다중 질의나 sparse 검색을 실행하는 실험이 아니다.

## 역할 분리와 변환 원칙

- 변환 담당은 원본 질문 100개만 읽고 기존 정제·정답·법령 원문·검색 결과·점수를 읽지 않는다. 원본 질문은 수정하지 않는다.
- 검수 담당도 원본과 새 변환문만 읽고 의미 보존을 전수 검수한다. 수정은 검색 실행 전에 작성자와 합의하고 이력을 남긴다.
- 실행 담당은 고정된 변환문·검수 SHA를 확인한 뒤 원래 코퍼스와 정답으로 평가한다. 실제 서비스 LLM API 호출이 아닌 에이전트가 작성한 고정 변환문의 검색 효과를 측정한다.
- 단일 짧은 질의에 질문의 쟁점과 일반 법률 개념을 표현한다. 답변·가상 조문·긴 가상 문서·여러 질의 목록을 만들지 않는다.
- 원본에 없는 사실·숫자·날짜·조건 충족·관할·법령명·조문번호·법적 결론을 추가하지 않는다. 명확한 상황의 일반 법률 개념 보강은 허용한다.
- 외국 관할, 개인 사건 현황 확인, 핵심 사실 누락 의도를 보존한다. 이를 국내 일반 법률 질문으로 바꿔 검색 성능을 올리지 않는다.

## 비교 조건

기존 독립 질문 100개와 같은 고정 정답을 사용한다. 실제 분류는 코퍼스 내 36개, 추가 자료 필요 44개, 지원 범위 밖 15개, 사실 부족 5개다. 원본·기존 의미 보존 정제의 200개 결과를 재사용하고 새 `legal_transformed` 질의 100개만 추가 추론한다. 기존 파일과 보고서는 덮어쓰지 않는다.

KURE-v1 revision `8b418a58414668e75532ed045c22d9ca018ae2b2`, 1024차원, 300자·중복 64자·문서 10,999개를 고정한다. Qdrant 전수 코사인 검색에서 조문별 최대 자식 청크 점수로 상위 10개를 평가한다. 임계값과 무관한 Recall@5/10·Hit·Complete·MRR@10·nDCG로 변환 효과를 비교한다. 신규 모드의 수용률은 이전 정제 임계값 0.59829341466087427을 그대로 쓴 진단이며 최적 기준값으로 주장하지 않는다.

이 질문셋의 이전 결과와 임계값 탐색이 이미 공개되어 새 변환 전략을 설계했다. 역할을 분리한 변환 작성이라도 이 비교 전체는 탐색·튜닝 평가다. 새로운 독립 held-out 검증으로 표시하지 않는다. 비교 후 질문·정답·변환을 같은 버전에서 조정하지 않는다. 정답 외 대체 관련 근거가 있을 수 있다는 기존 한계를 유지한다.

## 실행 및 보존

준비 스크립트가 원본·기존 결과·변환·검수·모델·코퍼스 해시를 묶어 manifest를 고정한다. 별도 터미널 하나에서 CPU 6개·메모리 8GB로 실행하고 완료·실패 시 KURE를 중지한다. 문서 색인은 읽기만 하며 새 질의 벡터와 결과는 이름이 분리된 Qdrant 컬렉션에 보존한다.

```powershell
.\evaluation\legal-retrieval\scripts\prepare-legal-query-transform.ps1
.\evaluation\legal-retrieval\scripts\run-kure-legal-query-transform.ps1 -ValidateOnly
$runner=Join-Path $PWD 'evaluation/legal-retrieval/scripts/run-kure-legal-query-transform.ps1'
Start-Process powershell.exe -ArgumentList @('-NoExit','-NoProfile','-ExecutionPolicy','Bypass','-File',('"'+$runner+'"')) -WorkingDirectory $PWD.Path
```

실행 후 반복 모니터링하지 않는다. 결과는 `reports/legal-query-transform-v1/kure-v1/`, 로그는 Git 제외 `artifacts/logs/`에 저장한다. 중단 플래그는 `artifacts/control/stop-kure-legal-query-transform-v1.flag`다. 변환 효과가 높아도 sparse의 정확 일치 기능을 대체했다거나 답변 정확도·실제 서비스 정제 성능이 검증됐다고 주장하지 않는다.

## 실행 전 준비 완료

변환 100개와 원본 일치를 확인했고 별도 검수에서 사실·결론 단정 위험 4건을 수정한 뒤 재검수했다. 원본 질문·정답·기존 정제는 변경하지 않았다. 미해결 검수 항목은 0개다. [변환문](transforms.json), [검수 이력](audit.json), [고정 manifest](../data/manifest.json)에 보존한다. 오프라인 사전검사에서 입력 해시·원본 일치·기존 200개 결과·8개 집계 행의 모든 지표 재계산 일치를 확인했다. 아직 실행 결과의 개선을 주장하지 않는다.

## 실행 완료

2026-10-20 원본·기존 정제 200건의 재사용과 새 변환 100건 평가를 완료했다. 새 변환의 코퍼스 내 Recall@5 28.70%, Complete@5 8.33%, MRR@10 0.3540이며 원본·정답·변환문은 실행 후 변경하지 않았다. [집계](../reports/kure-v1/README.md)와 [그래프·해석](../reports/kure-v1/interpretation.md)을 참고한다.
