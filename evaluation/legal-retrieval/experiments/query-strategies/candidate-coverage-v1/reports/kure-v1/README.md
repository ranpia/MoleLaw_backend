# Recall@50 후보 근거 회수 검증

동일한 코퍼스 내 36문항 × 세 입력 × 세 청크 = 324회, 각 상위 50개 조문을 Qdrant 전수 검색했다. 기존 질문 벡터를 재사용해 모델 추론은 하지 않았다.

Hit@5와 Complete@5를 우선 품질 지표로 유지하고 Recall@50은 재정렬 전 후보 50개에 필요한 근거가 얼마나 포함되는지 확인하는 보조 지표로 사용한다. 상위 50개를 조회해도 최종 상위 5개의 품질이 자동으로 좋아지는 것은 아니다.

기존 상위 5/10개 지표와 재조회 결과가 같은지 확인했다. 임계값·질문·정답·변환을 수정하지 않았다. 고정 정답 외 대체 근거 누락, 작은 표본, 이미 탐색한 튜닝셋이라는 한계를 유지한다. 실제 답변 정확도·새 독립 검증·재정렬 효과를 평가한 결과는 아니다.

## 법률 쟁점 변환의 후보 해석

법률 쟁점 변환 Recall@50은 300자 55.42%, 500자 56.57%, 700자 57.27%다. Hit@50은 각각 29/36·30/36·30/36, Complete@50은 12/36·11/36·11/36이다. 700자의 근거 회수율이 가장 높지만 300자는 모든 근거가 후보 안에 들어온 질문 수가 1개 더 많다. 작은 튜닝 표본이라 하나의 청크가 항상 우세하다고 판단하지 않는다.

500·700자의 50개 후보만 재정렬한다면 고정 정답 기준 최종 Hit@5는 최대 30/36, Complete@5는 최대 11/36을 넘을 수 없다. 이는 실제 재정렬 성능이 아닌 이상적인 후보 포함 상한이다. 후보 밖의 근거는 순서 변경으로 복구할 수 없어 후보 확대·하이브리드 검토와 재정렬 평가를 구분한다. 이번에 하이브리드나 KURE-v2를 실행한 것은 아니다.

Hit@5·Complete@5가 실제 최종 검색의 우선 지표이고, Recall@50·Hit@50·Complete@50은 재정렬 후보의 범위를 진단하는 지표다. 상위 50개를 그대로 답변 문맥으로 모두 넣어야 한다는 뜻은 아니다.
