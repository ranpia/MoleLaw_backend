# 검색 실험 계획

[실험 소개](README.md) · [실험별 자료와 상태](experiments/README.md) · [실행 안내](RUNBOOK.md)

이 문서는 앞으로 확인할 비교 순서와 조건을 관리한다. 완료 수치와 모델별 실행 상태는 각 실험 결과 문서를 따른다.

## Recall@50 모델 비교 마무리

KURE 기준선과 같은 질문·정답·코퍼스로 BGE-M3와 Qwen3-Embedding-0.6B를 비교한다. 300·500·700자와 원본·기존 정제·법률 쟁점 변환 질의를 사용한다. 최종 보고서가 저장된 모델만 완료 비교에 포함한다. [실험 조건과 결과](experiments/query-strategies/candidate-coverage-v1/README.md)를 따른다.

Hit@5·Complete@5를 공동 우선으로 보고 Recall@50은 후보에 정답이 들어오는 범위를 설명하는 데 사용한다. 점수 임계값은 적용하지 않는다. 완료 결과를 확인한 뒤 후속 검색 방식 비교의 모델 기준을 검토한다.

## 검색 방식별 비교 순서

| 순서 | 실험 | 확인할 것 |
| ---: | --- | --- |
| 1 | Legal Transformed + Dense | 완료 결과를 재사용하는 기준선 |
| 2 | Original + Transformed Dense | 원본 질의를 추가한 Multi-Query 효과 |
| 3 | Legal Transformed + BM25 | 단어 기반 검색의 독립 기여 |
| 4 | Dense + BM25 + RRF | 두 검색기를 결합했을 때의 개선 폭 |

현재 상세 계획은 KURE-v1·500자·중복 64자를 작업 기준으로 고정했다. 모델 기준을 바꾸면 실행 전에 계획과 입력 계약을 갱신한다. 질문·정답·법률 쟁점 변환문을 결과에 맞춰 수정하지 않는다. BM25 토큰화와 파라미터, 후보 수, RRF 규칙도 실행 전에 기록한다. [단계별 상세 계획](experiments/hybrid-search/ablation-v1/review/README.md)을 기준으로 진행한다.

## 별도 검토할 후보

한국어 추가 학습 모델, KURE-v2, 학습형 sparse, 재정렬, 차원 축소는 별도 실험으로 구분한다. 기존 dense·BM25·결합 비교와 분리해 변수를 하나씩 확인한다. [한국어 모델 후보 조사](experiments/model-comparison/review/korean-model-candidates.md)는 후보 검토 이력이다. 후보 확정 시 공식 모델 카드의 학습 자료·입력 방식·출력 차원·라이선스·실행 자원을 확인한다.

## 이후 확인과 실행 원칙

탐색한 질문셋으로 전략을 정한 뒤에는 새 질문과 정답을 고정해 별도로 검증한다. 임계값 탐색 후보를 초기화해도 이미 질문셋을 탐색한 사실은 사라지지 않는다. 답변 생성과 LLM의 근거 충분성 판단은 검색 순위와 구분해 검증한다.

무거운 다운로드·추론·평가는 별도 터미널에서 순차 실행하고 로그를 남긴다. 사용자가 모니터링할 때 채팅에서 반복 확인하지 않는다. 기존 입력·벡터·결과는 보존하고, 검증한 변경의 커밋·푸시는 별도로 관리한다.
