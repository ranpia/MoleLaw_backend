# 백엔드 재구축 요약

기준일: 2026-10-23, dev 작업 트리. 이 문서는 전체 방향만 요약한다.

## 현재 구조

MySQL은 사용자·상담·원문·근거·색인 상태, Qdrant는 벡터, Redis는 Refresh 상태를 담당한다. Spring AI 역할별 Client를 Java 서버가 순차 조정하며 권한·실행 한도·도구·저장·인용 검증은 서버가 통제한다.

최초 질문은 분류→검색→충분성 판단→필요 수집·ETL·재검색→답변으로 연결했다. 일반 법령 후보는 전체 페이지 리랭크 후 선별하고 저장 검증을 통과한 법령 한 건마다 재판단한다. 후속 상담은 Advisor와 최초 근거만 사용한다.

## 구현과 다음 단계

ETL·Qdrant 검색·근거 스냅샷·Advisor·역할별 모델 설정은 구현했다. 실제 모델 품질, usage 정산, 중단 복구·멱등성·분산 제어·운영 배포는 완료하지 않았다. AI Search는 별도 비교 코드만 준비했고 실 API 404 재시도는 보류했다. SSE는 후순위다.
