## 결정 기록 방식

결정 시 날짜·선택·적용 범위·이유·연결 작업 ID를 [확정 결정](confirmed.md)에 옮긴다. 구현 완료와 사용자 승인은 별도로 기록한다. 임계값·상위 후보 수·모델 추론 수준은 현재 코드의 초기값이며 평가 전 최종 정책으로 승격하지 않는다.
