# 법령 추가 수집·리랭크 개선

연결 작업: [P02·P04](README.md). 현재 동작은 [질문 라우팅](../question-routing.md), 판단 필드는 [판단 계약](../evidence-decision.md)을 따른다.

## 구현된 기준선

분류 질의로 기존 Qdrant를 검색하고 LLM이 ANSWER_READY·SEARCH_AGAIN·COLLECT_LAW·INSUFFICIENT를 제안한다. 재검색 횟수·유사도만으로 서버가 수집을 강제하지 않는다.

일반 법령 검색은 조건별 전체 페이지의 후보를 평가한 뒤 70점 이상 상위 2개만 상세 후보로 남긴다. 한 건을 수집·색인·저장 검증한 직후 재검색하고 충분성을 판단한다. 전체 페이지 검토가 예산 내 끝나지 않으면 해당 조건의 부분 후보로 색인하지 않는다. AI Search는 이 리랭크 대상이 아니다.

## 보완할 점

| 문제 | 조사·구현 방향 | 완료 증거 |
| --- | --- | --- |
| 제목만으로 규율 대상 판단 | 직접 규율·간접 관련·단어 일치 구분 평가. 세부 조문은 확보 후 검토 | 정답 법령 누락·잘못된 수집률 |
| 페이지별 점수 비교 | 페이지 순서·후보 조합 반복 평가. 필요 시 상위 후보 통합 리랭크 비교 | 선정 안정성·추가 비용 보고 |
| 70점·상위 2개 초기값 | 평가셋으로 누락과 비용을 비교하고 변경 제안 | D02 합격선과 사전 고정한 검증셋 |
| 미색인 법령에 재검색 반복 | 검색 범위·누적 시도·남은 행동을 판단에 제공하는 현재 방식 평가 | 불필요한 SEARCH_AGAIN·수집 누락률 |
| 사건 기준일 | 조회 시점과 적용 기준일을 분리하고 시행 버전 혼합 점검 | D03 정책·과거/현행/시행예정 회귀 |
| 매우 많은 페이지 | 시간·호출 한도 종료를 빈 결과와 구분하고 영속 작업 여부 검토 | P05·D04 연계, 부분 결과 미공개 검증 |

반복·변동 페이지와 중간 장애도 재현한다. 현재 실행 컨텍스트의 페이지 상태는 영속 복구 기록이 아니며 프로세스 재시작 후 자동 재개하지 않는다.

## 평가 구분

고정 색인 검색과 동적 수집 전체 흐름을 별도로 측정한다. 공항 주변 건축·민법/난민법·정확 조문·복합 쟁점·관련 법령 없음·구체 사실 누락·API 장애를 포함한다. 정답은 평가할 모델과 독립적으로 검토한다.

근거 ID가 유효한 것과 주장이 원문에 뒷받침되는 것은 다르다. 최종 답변의 인용 충실성과 근거 부족 상황에서의 부당한 답변도 평가한다. 수치·범위 선택은 [사용자 판단](../decisions/README.md)에 둔다.
