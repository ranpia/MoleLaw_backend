## 실행 원칙

현재 모델 배정·70점 기준·상위 2개는 평가 시작값이다. 다음 단계로 넘어가기 전에 실제 계측과 실패 사례를 남긴다. 더 큰 모델·더 긴 예산·더 많은 수집으로 부족한 원문이나 계약 오류를 숨기지 않는다.

문서만 수정한 작업은 실 API 검증으로 기록하지 않는다. 각 구현 완료 시 테스트·환경·외부 호출 여부와 남은 제한을 [검증 현황](../validation/validation-status.md)에 갱신한다. 이 계획은 실 API 재시도·배포·데이터 삭제의 포괄 승인 문서가 아니다.
