# SerpApi 보조 검색 검토

상태: **미도입·선택 대기 D07**. 연결 작업은 [P07](README.md)이며 현재 정상 상담 경로의 자동 fallback이 아니다.

## 검토 목적

법령 API만 장애이고 공식 웹 본문은 열리는 경우 공식 원문 후보를 찾는 보조 경로를 검토한다. API와 공식 웹이 함께 실패하면 원문을 확보할 수 없으므로 완전한 대체 수단으로 취급하지 않는다.

제안 흐름은 기존 검증 원문 검색→법령 API 제한 재시도→장애 확인→선택적 SerpApi→공식 본문 확보·버전 검증→원문 저장·ETL이다. 최초 질문에만 적용하며 후속 상담의 법령 추가 검색 금지는 유지한다. 동의 기반 판례 도구와 별개다.

## 채택한다면 지킬 경계

- 정상 빈 결과·낮은 유사도와 공급자 장애를 구분한다. 인증·파라미터 오류를 fallback으로 숨기지 않는다.
- 서버가 허용 도메인·URL·리다이렉트·응답 크기·사설 주소 접근을 검증한다.
- 스니펫·검색 순위·AI 요약은 근거가 아니다. 식별·시행일·본문 완전성을 검증한 공식 원문만 채택한다.
- MST나 버전이 없으면 임의 생성하지 않는다. 확보 실패는 후보 상태 또는 근거 부족으로 종료한다.
- 쟁점만 검색어로 보내고 개인정보·상담 원문·키는 외부 검색이나 로그에 노출하지 않는다.
- 공급자 비용·시간·재시도도 최초 요청의 예산에 포함하고 쿼터 소진·오류를 정상 빈 결과로 바꾸지 않는다.

## P07 평가

API만 장애/공식 웹까지 장애, timeout·429·5xx·인증 오류·빈 결과를 분리 재현한다. 비공식 문서·구법·일부 조문·잘못된 리다이렉트·지시문 삽입·쿼터 소진을 거부하는지 확인한다.

공식 본문 확보율·법령 버전 일치·추가 지연/비용·인용 충실성·후속 호출 0회를 측정한다. 효과가 부족하면 도입하지 않고 검증된 기존 근거의 범위를 안내한다. 허용 도메인·장애 임계값·비용·이용 조건·사용자 안내는 [D07](../decisions/README.md)에서 결정한다.

공급자 계약은 도입 시 [검색 API](https://serpapi.com/search-api)와 [상태·오류](https://serpapi.com/api-status-and-error-codes)를 다시 확인한다. 이번 문서 정리는 공급자 실 호출이나 신규 조사를 수행하지 않았다.
