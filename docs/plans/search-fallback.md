# 법령 API 장애 시 SerpApi 보조 검색 검토

상태: **검토 중·도입 미확정**. 법령·판례 API Tool 도입 결정과 구분한다. 상위 문서: [재구축 요약](../backend-rebuild-plan.md).

## 목적과 한계

법령 API 장애로 새 원문을 확보하지 못할 때 공식 웹 문서를 찾는 보조 경로를 검토한다. SerpApi Google Search는 `site:` 질의와 구조화된 검색 결과를 지원한다. 검색 결과는 원문 후보이며 법령 상세 API와 동등한 원문·시행일 검증을 보장하지 않는다. [공식 검색 API](https://serpapi.com/search-api)

API 서버만 실패하고 공식 웹 문서는 열리는 경우에 효과가 있을 수 있다. 공식 사이트 자체가 장애이면 검색 링크를 찾아도 본문을 확보할 수 없으므로 완전한 대체 수단으로 취급하지 않는다.

## 제안 흐름

`기존 MySQL 원문/Qdrant 검색 → 법령 API의 제한 재시도 → 장애 판정 → 선택적으로 SerpApi 검색 → 공식 본문 별도 확보·검증 → 원문 저장/ETL/근거 확정`

- 최초 질문에서만 실행한다. 후속 질문은 기존 스냅샷과 Advisor 기록만 사용한다.
- timeout·5xx·지속적인 429 등 의존성 장애를 전환 후보로 삼는다. 정상 빈 결과·낮은 유사도는 기존 후보/페이지 확장으로 처리하며 장애로 간주하지 않는다. 인증·파라미터 오류는 운영 오류로 기록하고 자동 전환으로 숨기지 않는다.
- 회로 차단·복구 확인과 공급자별 timeout/호출 한도를 검토한다. 보조 검색·본문 수집도 최초 요청의 남은 전체 예산 안에서 실행한다.
- 기존 근거가 충분하면 불필요한 보조 호출을 생략한다. 오래된 자료만 있으면 조회 시점과 적용 범위를 표시하고 최신성 확인 실패를 안내한다.

## Tool·원문 계약 제안

선택 Tool `searchOfficialLegalSources`를 별도로 두고 서버가 장애 상태·기능 설정을 확인한 뒤 호출하는 방안을 비교한다. 초기에는 모델이 직접 자동 호출하지 않는다.

| 구분 | 계약 제안 |
| --- | --- |
| 입력 | 개인정보를 제거한 법령명·조문/쟁점·기준일, 서버가 정한 허용 도메인과 페이지 범위 |
| 출력 | 제목·공식 URL·검색 스니펫·검색 시각·공급자 검색 ID·상태. 아직 검증되지 않은 후보로 표시 |
| 본문 확보 | 별도 서버 수집기가 공식 URL을 조회하고 법령 식별·조문·시행일·본문 완전성을 검증 |
| 근거 저장 | 검증된 본문만 저장, `sourceProvider`·URL·수집 시각·해시·버전·검증 상태 보존. MST 미확보를 명시하고 임의 생성하지 않음 |

검색 스니펫·검색 순위·AI 요약만으로 법률 결론을 만들거나 Qdrant의 검증 원문과 섞지 않는다. 원문 미확보/불완전/버전 불명확이면 후보로만 남기고 근거 부족으로 종료한다.

`site:law.go.kr`을 초기 검색 예시로 사용하되 실제 허용 도메인/경로는 별도 확정한다. 검색 연산자와 별개로 서버가 URL·리다이렉트·최종 호스트를 검사하며 사설 주소 접근, 과도한 응답 크기와 임의 URL 실행을 차단한다. 본문 파싱·이용 조건·차단 페이지 대응도 검증해야 한다.

## 장애·비용·개인정보

SerpApi는 HTTP 응답뿐 아니라 `search_metadata.status`·`error`를 확인하고 정상 빈 결과를 별도로 처리한다. 검색 응답 성공을 원문 수집 성공으로 간주하지 않는다. [상태·오류 문서](https://serpapi.com/api-status-and-error-codes)

API 키는 서버 비밀값으로 관리한다. 원문 상담 내용·이름·연락처를 외부 검색어로 보내지 않고 필요한 법률 쟁점만 추출한다. 검색 캐시 키·로그에도 개인정보를 넣지 않는다. 요금제·월 한도·호출 제한은 도입 시 공식 조건을 확인하고 초과 시 비활성화한다.

## 도입 판단과 검증

- [ ] 법령 API만 장애 / 공식 웹까지 장애를 분리 재현한다.
- [ ] API timeout·429·5xx·인증 오류·정상 빈 결과별 전환 조건을 검증한다.
- [ ] 스니펫만 있는 결과·비공식 문서·구법·중복·조문 일부만 확보한 결과를 근거에서 제외한다.
- [ ] 잘못된 URL/리다이렉트·문서 지시문·SerpApi 오류/쿼터 소진에서도 안전하게 종료한다.
- [ ] 공식 본문 확보율·법령 버전 일치·인용 정확도·추가 지연/비용·후속 호출 0회를 평가한다.
- [ ] 복구 시 기본 API 경로로 돌아가며 기존 상담방 스냅샷은 교체하지 않는다.

도입 전 결정: 장애 판정 임계값, 허용 도메인/본문 파서, 최신성·식별 정책, 비용/시간 한도, 이용 조건, 사용자 안내. 효과가 부족하면 저장된 검증 원문만으로 범위를 제한하고 재시도를 안내하는 방식을 유지한다.
