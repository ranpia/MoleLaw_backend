# 답변 중단·반복 검색·법령 링크 보완

2026-10-24 로컬 실행 로그에서 조문을 확보한 뒤에도 시행령 별표 등 미확보 쟁점 때문에 SEARCH_AGAIN을 반복하고 INSUFFICIENT 또는 시간 예산 소진으로 끝나는 요청을 확인했다. 검색 순위가 바뀌면서 이전에 채택한 조문이 다음 판단의 제한된 근거 목록에서 밀려나는 문제도 있었다.

- Qdrant 수집 판단에 ANSWER_PARTIAL을 추가했다. 실제 읽은 근거 ID와 미확인 쟁점이 모두 있어야 하며, 서버가 GENERAL_GUIDANCE로 제한한다. 최종 응답에는 미확인 쟁점을 별도 문구로 반드시 덧붙이고 기존 인용 검증을 수행한다. 빈 모델 응답이나 미확인 인용은 계속 거절한다. AI_SEARCH 경로는 이 행동을 사용하지 않는다.
- 이전에 채택한 근거를 최대 8개 우선 보존하되 출처 버전이 바뀌면 제외한다. 전체 후보 수와 본문 예산은 유지한다.
- 재검색 질의의 NFKC·대소문자·공백·문장부호를 정규화해 중복 여부만 판단한다. 실제 실행 질의는 변경하지 않는다. 실패 이력과 질의 변경 필요성을 판단 입력에 전달한다. LLM은 쟁점·조문번호 또는 명시적인 법령 검색 조건을 바꾸도록 지시받는다. 새 법령명 의미를 서버가 자동 추측하거나 조건을 몰래 완화하지 않는다.
- 현재 청커는 조문만 색인하므로 별표 본문을 같은 색인에서 반복 검색해도 얻을 수 없다는 제약을 판단 입력에 명시한다. 별표 수집 기능을 추가한 것은 아니다.
- 새 법령 원문과 AI 검색의 공개 링크는 `https://www.law.go.kr/lsInfoP.do?lsiSeq={MST}`로 생성한다. 기존 `/법령?lsiSeq=...` 링크는 답변 마크다운과 검색 API 응답에서 교정한다. 기존 원문·Qdrant payload는 수정하지 않아 출처 무결성 검증을 보존한다. 정상적인 이름 기반 법령 링크와 판례 링크는 유지한다.

저장된 MST 270551·284455·285279의 실제 상세 URL을 HTTP로 요청해 각각 200과 저장 원문에 있는 법령명이 HTML에 포함됨을 확인했다. 개별 요청마다 링크를 실시간 확인하는 기능은 추가하지 않았으며, 전체 법령의 모든 URL을 점검한 것은 아니다. 검사 결과는 로컬 `build/law-link-live-check.json`에 보관한다.

일반 안내 허용은 법률적 결론의 정확성 검증을 대신하지 않는다. 실제 사용자 질문의 전체 상담 흐름과 프론트엔드 링크 클릭은 별도 확인 대상이다.
