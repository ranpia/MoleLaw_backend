# 프로젝트 현황

MoleLaw 백엔드의 전체 기능과 남은 개발 범위를 요약한다. 인증·상담방·추천 질문·법령 RAG·동의 기반 후속 판례 검색과 스트림 응답을 구현했으며, 도메인별 상세 계약은 각 기능 문서에서 다룬다.

현재 코드는 PR #12까지 통합됐다. 최종 생성 단독과 고정 색인 전체 RAG 1상담을 확인했지만, 사건별 법률 품질·운영 예산·영속 복구·실제 저장형/전체 RAG 동시 부하 검증은 남아 있다. 브랜치 통합은 배포 완료를 뜻하지 않는다.
