## 보존·회복·다음 단계

자료는 Git 제외 `build/rag-prep/runs/rag-live-20261029T083706Z/`의 `probe.json`, `requests.jsonl`, `ledger.json`에 보존했다. provider 기록에는 역할·모델/effort/토큰 한도·usage·시간이 있고 질문/답변 원문·키는 없다. 클라이언트 기록에는 단계/이벤트와 경과 시간이 있다. 이번에 probe를 보완해 실패/연결 종료 때도 부분 이벤트를 남기도록 했다.

예상치 못한 추가 과금을 막기 위해 완료 후 게이트웨이를 **synthetic/internal 모드로 복귀**시켰다. 실제 사용량 ledger는 유지하며 초기화하지 않았다. 이후 합성 정상 완료·수집 차단 경로를 다시 점검했다. Grafana의 현재 mode와 마지막 합성 probe 시간은 이번 실제 모델 결과와 다를 수 있으므로 실제 측정은 보존한 실행 파일을 기준으로 읽는다.

이번에는 Java 코드를 수정하거나 전체 JUnit을 재실행하지 않았다. 유료 1상담과 Python probe의 합성 두 경로를 실행했다. 남은 3 공급자 시도로 동일한 약 5호출 상담을 다시 완료할 수 있다고 가정하지 않는다. 추가 상담/동시 증량은 호출 예산 범위와 실효 모델 옵션을 정리한 다음 별도 진행한다. 저장형 D·후속 대화·장시간 안정성은 여전히 미실행이다.
