# 실험 파일 구조 정리

`evaluation/legal-retrieval/`의 의미적으로 가까운 실험을 함께 관리한다. Java 도메인 패키지 배치는 별도 `domain-structure` 스킬의 범위다.

현재 목적별 진입점은 `evaluation/legal-retrieval/experiments/README.md`, 경로 대응은 `layout.json`이다. 공통 스크립트의 `Get-DataPath`, `Get-ReviewPath`, `Get-ReportPath`를 재사용한다. 같은 실험의 세 역할 디렉터리를 다시 최상위로 분리하지 않는다.

## 구조 결정

먼저 Git 상태와 현재 브랜치, 실험 README, `scripts/lib/Paths.ps1`, 호출 스크립트, `.gitattributes`, `.gitignore`를 확인한다. 기존 사용자 변경을 보존하고 실험 정리를 위해 개발 브랜치를 임의로 수정하지 않는다.

폴더 이름보다 실험의 질문·입력·비교 대상을 기준으로 분류한다. 이 저장소의 후보 그룹은 모델 비교, 검색 검증, 질의 전략, 하이브리드, 인프라다. 실제 파일을 확인한 뒤 필요한 그룹만 만든다. 같은 실험의 입력, 검토 자료, 결과는 가까이 두되 각각의 역할은 구분한다. 공통 실행 스크립트와 큰 공유 캐시를 실험별로 복제하지 않는다.

결과가 있는 실험, 검토만 한 후보, 실행 예정 계획을 명확히 표시한다. 청크 크기와 질의 버전이 다른 실험을 같은 결과처럼 합치지 않는다. 과거 모델 선정 기준과 현재 주요 지표 Hit@5·Complete@5도 구분해서 보존한다.

## 이동과 참조

- 이동 전 원본→대상 대응표와 파일 SHA-256을 만든다. 이동할 절대 경로가 저장소 내부인지 확인하고 대상 충돌은 덮어쓰지 않는다.
- 고정된 JSON, JSONL, CSV, PSV, 매니페스트와 바이너리는 바이트 그대로 이동한다. 경로를 보기 좋게 바꾸려고 해시로 연결된 원본 내용을 재직렬화하지 않는다. 변경이 필요한 고정 입력은 별도 실험 버전으로 만든다.
- 고정 자료 내부의 과거 경로는 출처 기록으로 보존할 수 있다. 현재 경로는 중앙 경로 해석기나 대응표에서 제공하고 이 차이를 문서화한다.
- 실행 경로는 `Paths.ps1` 같은 공통 지점으로 모은다. 데이터/보고서 디렉터리 인자를 전달하는 기존 호출 계약을 유지한다. 상대경로를 일괄 치환하기 전에 기준 디렉터리를 확인한다.
- Markdown 링크와 이미지 경로는 이동 전 문서 위치에서 대상을 해석한 뒤 새 상대경로를 계산한다. 루트 README, docs, Docker 안내, 실행 예시와 스크립트 호출부도 확인한다.
- `.gitattributes`의 고정 데이터 줄바꿈 정책과 `.gitignore`의 캐시·로그 제외 경로를 같이 옮긴다. `artifacts/`의 큰 캐시와 원본 스냅샷은 보존하고 Git에 추가하지 않는다.
- 파일을 지울 때는 참조·재현 가능성·사용자 변경을 확인한다. 단순히 오래되었거나 결과가 낮다는 이유로 제거하지 않는다. 이동 후 비어 있는 폴더는 제거할 수 있다.

## 검증과 마무리

이동 전후 고정 파일 해시를 비교한다. Git 인덱스에 올릴 경우 필터와 줄바꿈 처리로 바이트가 달라지지 않았는지도 확인한다. 변경한 PowerShell을 파싱하고 해당 경로를 사용하는 계약 테스트와 `-ValidateOnly` 검증을 실행한다. 문서 링크와 이전 경로 참조를 검색한다. 원래 실패하던 검사와 이동으로 생긴 실패를 구분한다.

구조 정리만을 검증하려고 모델 추론이나 전체 평가를 재실행하지 않는다. 검증을 위해 준비 스크립트를 호출할 때 고정 입력을 덮어쓰지 않는 모드를 확인한다. PowerShell 5.1에서 한글 실행 스크립트는 UTF-8 BOM을 사용하고, 문서는 UTF-8로 읽고 쓴다.

최상위 안내에는 목적별 진입점과 현재 기준선을 둔다. 상세 결과는 해당 실험 폴더에 두고 요약을 여러 문서에 복제하지 않는다. 완료 보고에는 새 위치, 보존한 자료, 실제 통과한 검사와 남은 작업을 포함한다. Qdrant도 변경한다면 `qdrant-experiment-management` 스킬을 함께 적용한다.
